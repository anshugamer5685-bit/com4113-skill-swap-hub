📚 About this project

The Community Skill Swap Hub is designed as a pilot web application that can grow into a full-scale platform where learners exchange skills and resources.

Project goals
Overview
  • Provide an intuitive front-end for browsing and sharing skill resources.
  • Demonstrate basic UI patterns: forms, search, filtering, and feedback.
  • Prepare a foundation that can later connect to a back-end API and database.
Legal & ethical considerations
Discussion

In your written documentation, you should discuss privacy, consent, copyright, accessibility, and responsible AI use. For example:

  • How user data (profiles, emails, hobbies) will be stored securely when the back-end is implemented.
  • How copyright is handled for shared resources (e.g. linking to official content vs. hosting copies).
  • How you will comply with institutional policies on generative AI and academic integrity.
Future scaling ideas
Future work

The MVP is intentionally simple and front-end only. In the second semester you could:

  • Implement real authentication and user accounts with a server-side stack.
  • Persist resources, ratings, and comments using a database and REST/GraphQL API.
  • Add optional enhancements like bookmarking, richer profiles, or voting systems.
